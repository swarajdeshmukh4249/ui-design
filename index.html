What it does

A small instrument for a big question: does following the sun, with reflectors, really produce more power? The dashboard reads the Arduino over USB, plots every sample, labels each run A to D and compares them without inventing a single number.

    FAQ

    How do I connect the Arduino?

    Open this page in desktop Chrome or Edge from http://localhost (see README). Close the Arduino Serial Monitor and Plotter. Then choose USB Serial in Live measurements, match the baud rate (default 115200), press Connect and pick the board's port.

    What should the Arduino send?

    One JSON object per line, about once per second: {"voltage_V":5.2,"current_mA":180.0}. Power is always calculated here as voltage_V × current_mA ÷ 1000. Debug lines that aren't valid JSON are ignored and counted.

    What do Fresh, Stale and Disconnected mean?

    Fresh: a valid sample arrived within the last 5 seconds. Stale: connected, but no valid sample for more than 5 seconds; the last value stays visible but faded. Disconnected: no data source. If the cable is unplugged mid-recording, the recording stops and every captured sample is kept.

    Is the demo data real?

    No. Demo mode generates plausible, smoothly varying values so the interface can be reviewed without hardware. It is labelled Simulated data everywhere, and demo sessions can never be compared with hardware sessions.

    How is average power calculated?

    As the mean of the individual power samples, not average voltage × average current. Mean power change is (test − baseline) ÷ baseline × 100, and shows N/A when baseline power is zero or negative.

    Where is my data stored?

    In this browser on this device (IndexedDB). It is not backed up to the cloud, so export important sessions as CSV.

    How to connect the Arduino

    Web Serial in this browser
    —
    Secure context (HTTPS or localhost)
    —
    1. Use desktop Chrome or Edge. Firefox and Safari do not support Web Serial.
    2. Open this page from http://localhost or HTTPS (see README).
    3. Close the Arduino IDE Serial Monitor and Serial Plotter. Only one program can use the port.
    4. In Live measurements, select USB Serial, match the baud rate to Serial.begin() (default 115200), press Connect and choose the port.

    Expected format, one line per reading:

    {"voltage_V":5.2,"current_mA":180.0}
